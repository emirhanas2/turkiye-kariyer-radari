# Katkı rehberi

Katkılar memnuniyetle karşılanır. Değişiklik yapmadan önce mevcut issue'ları kontrol et; yeni kaynak veya ayrıştırıcı değişikliği için örnek bir herkese açık ilan URL'si ekle.

## Yerel geliştirme

```bash
git clone https://github.com/emirhanas2/turkiye-kariyer-radari.git
cd turkiye-kariyer-radari
npm test
npm start
```

Pull request gönderirken:

- Değişikliğin amacını ve kullanıcıya etkisini açıkla.
- Yeni kaynak bağlantılarının yalnızca izin verilen alan adına gittiğini doğrula.
- Kategori, reklam veya yönlendirme bağlantılarının ilan olarak kaydedilmediğini test et.
- `npm test` sonucunun başarılı olduğundan emin ol.
- Kişisel veri, çerez, parola veya `data/` klasörünü commit etme.

Kaynak sitelere yüksek sıklıkta istek gönderen veya giriş kontrollerini aşan değişiklikler kabul edilmez.
